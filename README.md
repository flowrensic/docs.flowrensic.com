# docs.flowrensic.com

Docs for Flowrensic, built with [Mintlify](https://mintlify.com). Config is `docs.json`, pages are `.mdx`.

    npm i -g mint 
        OR
    npm i -g mint --registry=https://registry.npmjs.org/
    mint dev --port 3001        # http://localhost:3001
