With Connect over JSON, a call is a `POST` to `/<package>.<Service>/<Method>`:

```bash
curl -X POST localhost:8080/flowrensic.v1.CatalogService/RegisterNamespace \
  -H 'content-type: application/json' \
  -d '{"deployEnv":"prod","namespace":"default","endpoint":"127.0.0.1:7233"}'
```

| Service | Methods |
| --- | --- |
| [CatalogService](/api-reference/catalog-service) | RegisterNamespace, ListDeployEnvs, ListServers, ListNamespaces |
| [IngestService](/api-reference/ingest-service) | Worker and collector push path, 13 methods |
| [QueryService](/api-reference/query-service) | Runs, findings, metrics, replay sets, cost, 26 methods |

The source of truth is `proto/flowrensic/v1/services.proto` in the flowrensic repo.
